# Homebrew Tap for Photo Selector Toolbox

Official Homebrew tap for [Photo Selector](https://github.com/alexpp90/photo-selector).

## Installation

### macOS Desktop Application (Recommended)

To install the native macOS Desktop application (Cask):

```bash
brew install --cask alexpp90/tap/photo-selector-toolbox
```

Or tap first, then install:

```bash
brew tap alexpp90/tap
brew install --cask photo-selector-toolbox
```

### Command Line / Legacy Formula

```bash
brew install alexpp90/tap/photo-selector-toolbox
```

### Nightly Builds

```bash
# macOS Desktop App (Nightly)
brew install --cask alexpp90/tap/photo-selector-toolbox@nightly

# CLI (Nightly)
brew install alexpp90/tap/photo-selector-toolbox@nightly
```

## Updates

To update installed packages to the latest release:

```bash
brew update
brew upgrade
```
